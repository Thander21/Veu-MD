# V.E.U. MD — Manifesto Narrativo & Filosofia de Marca

> **"O Véu que se abre. O texto que respira."**  
> **"Ver, Editar e Usar — Sem a poluição das tags na tela, com a integridade pura do Markdown no disco."**

```

                 │                  V.E.U. MD                   │

                                        │
           ┌────────────────────────────┴────────────────────────────┐
           ▼                                                         ▼
   [ O ACRÔNIMO DO FLUXO ]                                   [ A METÁFORA POÉTICA ]
   Português: Ver, Editar, Usar                              "O Véu da Sintaxe Crua"
   Inglês:    View, Edit, Use                                • Descortinar o ruído visual
   MD:        Markdown / Modern Document                     • Revelar o pensamento limpo
```

### 1.1. O Ciclo Vital da Palavra (V.E.U.)
* **V — Ver (View):** A experiência da leitura pura e imersiva. Nenhuma cerquilha `#`, asterisco duplo `**` ou sinal de maior `>` polui o olhar. O leitor contempla tipografia calibrada, títulos hierarquizados, realces sutis e respiro visual.
* **E — Editar (Edit):** O ofício da criação sem atrito. A fluidez do modo WYSIWYG completo (estilo Word/Pages), onde formatações, tabelas, blocos de código e listas são manipulados instantaneamente, com motor de estilos renderizado direto pela GPU (CSS Custom Properties nativas, zero Virtual DOM).
* **U — Usar (Use):** O Markdown como instrumento de poder técnico. O arquivo não fica preso em silos: ele é consumido pelo terminal contextual embutido (PTY), versionado no Git, exportado para sistemas e lido por agentes de IA.

### 1.2. O Paradoxo Resolvido
Na história dos editores modernos, o escritor sempre enfrentou um dilema:
* **Ou a lentidão dos navegadores disfarçados:** Aplicativos Electron pesados, consumindo 300MB a 500MB de RAM apenas para abrir notas.
* **Ou a feiura da sintaxe exposta:** Editores de texto puro que obrigam o autor a redigir cercado por caracteres mecânicos de controle.

O **V.E.U. MD** resolve esse paradoxo como um véu translúcido:
* O véu cobre o ruído visual durante a escrita;
* Mas o arquivo em disco permanece **Markdown padrão GFM puro e universal**;
* O motor em Rust (Tauri v2) consome apenas ~35MB de RAM: leve como seda, forte como aço.
